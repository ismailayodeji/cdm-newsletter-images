# CDM Newsletter Images

Public image assets for CDM MEE newsletter emails.

## How to use

1. Add your image to the appropriate folder (e.g. `vol4/speedboat/`)
2. Commit and push
3. Get the raw URL:
   `https://raw.githubusercontent.com/ismailayodeji/cdm-newsletter-images/main/FOLDER/filename.png`
4. Paste that URL into the **Image URL** field in the newsletter generator

Raw URLs work in all email clients including Outlook Classic — no login required.
